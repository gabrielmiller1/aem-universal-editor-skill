# Advanced use cases

The agent should be capable of designing these patterns.

## AI assisted content action

- identify selected content
- open modal
- collect tone/locale/options
- call Runtime Action
- show preview
- apply accepted fields
- refresh/update authoring state

## Product picker

- custom data type renderer
- product search UI
- backend/API query
- value normalization
- field update through host field API
- error and empty states

## Content advisor rail

- custom properties rail
- read editor state
- identify current editable
- fetch validation/advice
- deep-link/select affected editable
- refresh after correction

## External workflow launcher

- header action
- collect current location/content
- call protected backend
- show job result/modal
- navigate/refresh when required

## Diagnostics rail

- display current editable/resource mapping
- model/filter IDs
- authoring resource URNs
- detected instrumentation issues
- never expose secrets/tokens
